# G4 Voice — instaladores

Ditado por voz para Windows: **segure o atalho, fale e solte**. O texto aparece onde está o cursor, em qualquer aplicativo.

## Instalar

1. Abra a [Release mais recente](../../releases/latest) e baixe o **`G4Voice-win-Setup.exe`**.
2. Execute o arquivo. A instalação é por usuário e não pede senha de administrador.
3. O instalador ainda não é assinado digitalmente. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.

Quem já tem o G4 Voice instalado recebe as versões novas **automaticamente**. A atualização é baixada em segundo plano e entra quando o app é reiniciado ou fechado.

## Requisitos mínimos

- Windows 10 22H2 ou Windows 11, 64 bits (x64)
- Processador x64 com 4 núcleos e AVX2; 8 GB de RAM
- 700 MB livres em disco
- GPU com suporte a Vulkan recomendada (a transcrição roda no computador)

## Sobre este repositório

Este repositório guarda só os instaladores e os pacotes de atualização. O código-fonte é mantido em um repositório privado da G4 Educação.
